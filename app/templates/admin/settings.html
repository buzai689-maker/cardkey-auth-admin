客户端验证 API

客户端(被授权的程序)用卡密 + 机器码调用以下接口:

GET  /api/v1/pubkey  服务器公钥(Ed25519 验签 + X25519 信封),客户端 pin
POST /api/v1/secure  加密信封 {epk,n,ct},内含 {op,...} — 唯一入口,全程密文

op ∈ activate / verify / unbind / heartbeat / session。明文端点已关闭(调用返回 404), 卡密等字段不再明文上线。

返回 {"success":bool,"message":str,"data":{...}}。详见 README。
