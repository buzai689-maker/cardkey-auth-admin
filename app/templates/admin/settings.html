客户端验证 API

客户端(被授权的程序)用卡密 + 机器码调用以下接口:

POST /api/v1/secure    加密信封 {epk,n,ct},内含 {op,...} — 推荐,全程密文
明文端点(靠 TLS 保密):
POST /api/v1/activate  {"code","device_id","device_name?"}
POST /api/v1/session   {"code","device_id","client_pub","nonce"}
POST /api/v1/heartbeat {"code","device_id","nonce"}
POST /api/v1/verify    {"code","device_id"}
POST /api/v1/unbind    {"code","device_id"}

返回 {"success":bool,"message":str,"data":{...}}。详见 README。
